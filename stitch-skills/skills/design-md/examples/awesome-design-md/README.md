# awesome-design-md

Vendored copy of [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md), a curated collection of `DESIGN.md` files analyzed from real-world websites (Stripe, Linear, Notion, Vercel, etc.).

Each subdirectory under `design-md/` holds one site's `DESIGN.md` (the semantic design system description) and a `README.md`. Use these as reference examples of the `DESIGN.md` format produced by the [`design-md` skill](../../SKILL.md), or as starting points for prompting Stitch/other agents to match an existing site's visual language.
