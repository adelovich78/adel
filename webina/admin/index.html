Trouver des établissements

Recherche dans OpenStreetMap, la carte libre : nom, téléphone, e-mail et site quand ils y sont renseignés. Les établissements sans site apparaissent en premier.

Variables remplacées pour chaque prospect : {isletme} nom de l'établissement · {ilce} quartier · {demo} lien vers l'exemple de son métier. Votre signature et le lien de désinscription sont ajoutés automatiquement.

    Importer une liste

    Dans Excel, sélectionnez le tableau avec sa ligne de titres, copiez (Ctrl + C) et collez ici. Un fichier CSV fonctionne aussi. Colonnes reconnues : İşletme / nom, Kategori, İlçe, e-posta, Telefon, Web sitesi, Kaynak. Les doublons sont ignorés.
